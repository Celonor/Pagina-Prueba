IMAGENES DEL SITIO
==================

El HTML y el JavaScript apuntan a esta carpeta usando rutas como:
  img/photo-1551698618-1dfe5d97d256.jpg

IMPORTANTE
----------
No pude descargar automáticamente los originales desde Unsplash en este entorno porque no hay conexión de red. Por eso, esta carpeta queda preparada con el listado de nombres y enlaces originales; el sitio conserva una URL de respaldo para que las imágenes puedan seguir apareciendo con conexión a Internet.

Para usar archivos locales:
1. Descargá cada imagen desde el enlace de abajo.
2. Guardala dentro de esta carpeta `img/`.
3. Renombrala exactamente al nombre indicado (por ejemplo, `photo-1551698618-1dfe5d97d256.jpg`).
4. No cambies la extensión si el archivo descargado no es JPG; si la cambiás, actualizá también la ruta en HTML/JS.

OTROS RECURSOS
--------------
- Las imágenes JPG, PNG, WebP y GIF pueden estar dentro de `img/`.
- Los GIF funcionan en una etiqueta <img> igual que una imagen normal.
- Para videos MP4/WebM, recomiendo crear una carpeta `videos/` y usar una etiqueta <video> en HTML. No alcanza con cambiar el nombre del archivo: el elemento HTML debe ser de video.
- Si reemplazás una imagen por un GIF, podés conservar el nombre del archivo si actualizás la extensión y también la ruta en el código.
