BENNETT & CLIVE — proyecto separado

Estructura:
- index.html: estructura HTML
- css/style.css: estilos CSS originales
- js/script.js: JavaScript original y configuración de respaldo de imágenes
- img/: recursos gráficos y README con nombres/enlaces de imágenes

Abrí index.html en el navegador. Tailwind CSS y Google Fonts siguen cargándose desde sus CDN, como en el original. Para ver los recursos locales, colocá los archivos en img/ con los nombres exactos indicados en img/README.txt.

No se modificó intencionalmente el contenido textual ni la lógica visual; el cambio principal fue separar CSS/JS y preparar las rutas de imágenes.
